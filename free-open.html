开源模型免费 API

这里是目前模型最强的免费区：Kimi K3、GLM-5.3、DeepSeek、Llama 等前沿开源模型，都有官方免费推理入口。

模型最强

NVIDIA NIM 免费 Endpoints

一句话
NVIDIA 官方的模型推理平台，大量开源大模型提供免费 endpoint。
免费额度
免信用卡，key 以 nvapi- 开头；约每分钟 40 请求，按模型独立计算（一个模型被限流可换另一个）。
官网
build.nvidia.com
接口格式
OpenAI 兼容，Base URL：https://integrate.api.nvidia.com/v1
可用模型标识
moonshotai/kimi-k3 · z-ai/glm-5.3 · deepseek-ai/deepseek-v4.1-flash · google/gemma-4-31b-it · meta/llama-4-maverick-17b-128e-instruct
适合场景
Agent 编程、复杂推理、多模型横评；已有 OpenAI SDK 的项目几乎零改造成本。
注意事项
免费档无 SLA，模型可能随时调整；429 后不要硬等，换模型继续。
速度最快

Groq

一句话
以超低延迟著称的推理平台，自研 LPU 芯片，免费 tier 可用。
免费额度
免费注册，每日 token 上限（按模型档位），无需信用卡。
官网
console.groq.com
适合场景
对延迟敏感的对话、实时应用；Llama、Mixtral 等模型。
注意事项
免费档有速率限制；模型库偏向 Meta/Mistral 系。
免 key

Pollinations.ai

一句话
免注册、免 key 的免费文本（+图像）API，URL 里直接带 prompt。
免费额度
匿名可用，有合理使用限制。
官网
pollinations.ai
适合场景
快速 demo、教学、个人小工具；不想注册时的第一选择。
注意事项
不适合生产环境；不要传敏感内容。
聚合

OpenRouter（免费档）

一句话
聚合上百个模型的统一 API，其中一部分模型提供免费调用。
免费额度
标注 free 的模型免费，有速率限制；一个 key 通吃。
官网
openrouter.ai
适合场景
模型横评、快速切换；OpenAI 兼容格式。
注意事项
免费模型名单会变，下单前看清 :free 标识与限速说明。

选型速查

  • 啃硬任务（Agent 编程、复杂推理）：NVIDIA 上的 moonshotai/kimi-k3、z-ai/glm-5.3。
  • 轻量问答/解释代码：google/gemma-4-31b-it，又快又省。
  • 要速度：Groq。
  • 不想注册：Pollinations.ai。
