ChatGPT 免费 API 渠道

先说结论：OpenAI 官方 API 没有常驻免费 tier，按量预付费。下面几条是合法、可验证的免费路。

真 GPT · 推荐

GitHub Models

一句话
GitHub 官方提供的模型试用平台，可免费调用 GPT-4o-mini / GPT-4o。
免费额度
每天约 150 次请求（按模型略有差异）。
官网
github.com/marketplace/models
适合场景
学习、原型验证、轻量调用；OpenAI SDK 只需换 base_url。
注意事项
需要 GitHub 账号，无需信用卡；额度按天重置，不适合高并发。
微软官方

Microsoft Copilot

一句话
微软的 AI 助手，背后是 OpenAI 模型，有免费 baseline 体验。
免费额度
浏览器打开即用基础版；登录后对话更长、功能更多。
官网
copilot.microsoft.com
适合场景
日常问答、写作、搜索增强；不是 API，是网页/应用形态。
注意事项
这是对话产品，没有开放 API；重度用户会被限速。
官方 · 限时

OpenAI 新用户测试额度

一句话
新注册的 API 账号有时会获赠小额测试金，用于跑通集成。
免费额度
金额不固定（第三方报告约 $5），OpenAI 未官宣承诺。
官网
platform.openai.com
适合场景
第一次接 OpenAI API 时的冒烟测试。
注意事项
不要轻信"注册即送 $5"的营销话术，以你账号后台实际到账为准；之后是预付费模式。

避坑

远离这三类：① 兜售"免费 OpenAI API key"的网站（多为盗号或转售，随时失效还可能盗你数据）；② "key 生成器"（100% 骗局）；③ 要求你先付"激活费"才给免费额度的。免费的东西如果先要钱，就是生意不是福利。
