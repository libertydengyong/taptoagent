公益 AI 站辨别指南

先声明立场：本页不罗列任何具体公益站链接。公益站生死周期按周计，今天能用的名单明天可能就跑路——名单会过期，方法不会。下面是我们的收录标准，和你自己辨别时可用的同一套尺子。

靠谱公益站的 6 条标准

  1. 不索要你的账号密码——只让你用它自己的 key/渠道。凡是要你交出 OpenAI、Anthropic 账号密码的，直接拉黑。
  2. 全站 HTTPS，且无诡异跳转——付款页、登录页跳到陌生域名，立刻停手。
  3. 限速规则写在明处——靠谱站会公开"每分钟 X 次、每天 Y 次"；规则含糊其辞的，多半随时改。
  4. 有公开的社区口碑——在 V2EX、GitHub、Telegram 群里能搜到真实用户讨论，而不是只有它自己的宣传帖。
  5. 免费额度与成本对得上——声称"无限 GPT-4、无限 Claude"却没有任何付费项的，钱从哪来？想清楚再上。
  6. 有明确的跑路预案意识——好的公益站会告诉你数据保留政策、关停通知方式；什么都不说的，默认它明天就消失。

7 个危险信号，见一个就跑

  1. 注册时索要身份证、手机号+验证码"双保险"（超出正常验证范畴）。
  2. "免费"但要求先充值"激活"、"押金"、"验证金"。
  3. API 返回内容与你发送的 prompt 风马牛不相及（可能在拿你的请求练别的东西）。
  4. 站内嵌套多层跳转、弹窗下载"专用客户端"。
  5. 客服只在充值前秒回，充值后消失。
  6. 域名注册不到 3 个月，却自称"运营三年"。
  7. 要求你把它的 key 部署到生产环境（个人 key 随时回收，生产必炸）。

给开发者的底线建议

  • 公益 key 只用于学习和测试，永远不要进生产环境、不要传用户隐私数据。
  • 重要项目走官方渠道（Gemini、NVIDIA NIM 的免费档足够稳）。
  • 定期换 key、定期检查账单——免费的东西最贵的是你的数据。
