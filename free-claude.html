Claude 免费 API 渠道

先说结论：Claude 没有常驻免费 API tier。免费的 Claude 主要在网页版；API 侧只有小额测试金和定向计划。

人人可用

claude.ai 免费版

一句话
Anthropic 官方网页版，免费永久可用（有用量上限）。
免费额度
每天约 30–100 条消息（按负载浮动），高峰期会被限。
官网
claude.ai
适合场景
日常对话、写作、分析；注意这是网页版，不开放 API。
注意事项
Claude Code 等开发工具需要付费计划或 API key，免费版带不动。
官方 · 测试

Console 新用户测试金

一句话
新注册 platform.claude.com 开发者账号可能获赠小额测试金。
免费额度
第三方报告约 $5；Anthropic 未官宣固定金额，以后台为准。
官网
platform.claude.com
适合场景
跑通一次 API 集成、评估模型效果。
注意事项
用完即按量付费；开户条款经常静默调整，动手前先看计费页。
定向计划

Claude for Open Source / 学生计划

一句话
Anthropic 给开源维护者、学生的定向资助计划，额度可观。
免费额度
按项目/身份审批，曾有数月顶级计划、数百美元 API 额度等案例。
官网
anthropic.com 站内搜索 programs
适合场景
维护有影响力开源项目、在校学生做课程与毕设。
注意事项
需要申请+审核，不是即开即用；各期名额与条款会变（创业计划 2026-10 起暂停重审）。
曲线

云厂商通道（Bedrock / Vertex / Azure）

一句话
AWS、Google Cloud、Azure 上架了 Claude 模型，走你的云账单。
免费额度
Claude 本身不免费，但云厂商的新用户免费额度（如 GCP $300）可间接覆盖。
适合场景
已有云账号的团队；需要企业合规与 VPC 内调用。
注意事项
本质是"用云的免费额度付 Claude 的账"，额度烧完即停。

红线：共享 key 站碰不得

坚决不用"免费 Claude API key"共享/轮换站。那些 key 来路不明（盗刷、转售），随时失效；更重要的是你的 prompt 会经过别人的服务器——代码、密钥、隐私全裸奔。省这点钱不值得。
